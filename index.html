BES INWARD

A system that watches its own operator. Not “who are you?” — “are you behaving like yourself?” It learns the operator’s behavioural signature, then catches a hijacked or scripted run by how it behaves, with no credential changing hands. booting kernel…

Identity is insufficient; behaviour is authoritative. An impostor fails one of exactly two ways — it is overly regular (scripted automation, clockwork rhythm) or randomly uncorrelated with the operator (a hijack, a different mix of actions). One-class: it models the operator, never the attacker, so a hijack it has never seen still flags. (Behavioural Entropy Signatures, Gary W. Floyd.)
